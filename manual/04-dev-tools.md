## `#/prompt-lab` — 프롬프트 실험실

로그인 후 주소창에 `#/prompt-lab`. AI 에게 보내는 프롬프트 템플릿을 실행·비교하는 개발용 화면입니다.

1. 템플릿 선택 (`character`, `diagnose`, `advice`, `environment`, `checklist`, `monthly-report`, `species`)
2. 입력 샘플 선택 (`public/prompts/samples/<이름>-input.json`) — 입력 JSON 은 직접 고쳐도 됩니다.
3. 버전: 한 개(`v1`) 또는 쉼표로 비교(`v1,v2`) → 버전별 결과가 나란히 표시
4. `character`·`diagnose` 는 사진 파일 선택 필요, 반복 횟수 1~5
5. [실행하기] → 결과 카드마다 걸린 시간, 응답, **모양 검사**(`checkShape` → 통과/확인 필요), 채워진 프롬프트
6. [결과 JSON 내려받기] → `<이름>-<버전>-<YYYYMMDD-HHmm>.json`

* **mock 모드는 템플릿 본문을 쓰지 않고 고정 응답을 돌려주므로**, 화면·검사 흐름만 확인됩니다. 문구 품질 비교는 real 모드에서 하세요.
  (`species` mock 은 이름을 비워 두는 설계라 "name 글자가 없어요" 가 뜨는 것이 정상)
* 모양 검사는 키·배열 개수만 봅니다. "흙이 축축한데 물주기를 권하는지" 같은 안전성은 사람이 읽고 판단합니다.
* 내려받은 파일에는 입력·프롬프트가 들어갈 수 있으니 사진·개인 정보를 넣지 마세요.
* 템플릿 개선 절차와 기록 표 → 저장소 [README 의 "프롬프트 템플릿 관리"](../README.md#프롬프트-템플릿-관리)

## AI로 새 식물 종류 추가 — 테스트할 때 주의

`#/plants/new` 에서 목록에 없는 이름(2글자 이상)을 입력하면 **[🤖 'OO' AI로 새 식물 추가하기]** 버튼이 나오고,
확인 창에서 [이 정보로 추가하기]를 눌러야만 `users/{uid}/customSpecies/ai-<이름>` 에 저장됩니다.

* **mock 모드에서는 AI 가 판단하지 않아서 "쓰레기통" 같은 이름도 식물로 만들어집니다.** (확인 창에 🧪, `source: "MOCK"`)
  식물 판정을 시험하려면 real 모드로 하세요.
  * real 모드 예: "쓰레기통" → "식물 이름으로 찾지 못했어요", "대마" → AI 호출 없이 안내, "아레카야자" → 확인 창에 🤖
* 테스트로 만든 종류는 아직 수정·삭제 화면이 없습니다. Firebase 콘솔 → Firestore → `users/{내 uid}/customSpecies` 에서 직접 지우세요.
  (그 종류로 등록한 식물은 "내 식물 관리"에서 삭제)

## 전체 통합 확인 순서 (한 계정으로 처음부터)

1. 회원가입 → 첫 식물 등록(사진 → 캐릭터) → 메인
2. AI 환경 분석 (조도 측정 → 점수 → 조언)
3. 성장 캘린더 사진 진단 → 관찰 필요(ALERT, 돋보기)
4. 체크리스트 물주기 Safe-Lock — [아직 축축해요] → 2일 연기 / [말라 있어요] → +20 EXP, 레벨업
5. 체크리스트 [사진으로 상태 확인하기] → 질문·처방까지 진행 (P1 + P3 연결)
6. 로그인 → 체크리스트 알림 → 알림 눌러 체크리스트로 이동 (P3 + P4 연결)
7. `#/dev` 지난달 샘플 기록 → 다시 로그인 → 리포트 알림 → 리포트 열람 (P4 + P6 연결)
8. `#/dev` 에서 AI·날씨를 real 로 바꿔 2~7을 한 번 더
