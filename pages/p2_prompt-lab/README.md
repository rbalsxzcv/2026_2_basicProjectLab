# P2 프롬프트 실험실

실행되는 P2 기능은 앱 경로에 구현했습니다.

- 실험실 화면: `public/js/pages/prompt-lab.js`
- 화면 스타일: `public/css/pages/prompt-lab.css`
- 샘플 입력: `public/prompts/samples/`
- 사용법과 버전 기록: `public/prompts/README.md`
- 개발 화면 연결: `public/js/pages/dev-ui.js`의 `[P2]` 구역

`#/prompt-lab`은 개발용 도구이며, 프롬프트 품질 비교는 AI real 모드 설정이 필요합니다. mock 모드는 고정된 예시 응답으로 화면과 JSON 모양 검사 흐름을 확인합니다.
