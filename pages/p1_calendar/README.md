# P1 성장 캘린더

실행되는 P1 코드는 앱 구조와 `P1_calendar.md`가 지정한 경로에 구현했습니다.

- 화면: `public/js/pages/calendar.js`
- 화면 스타일: `public/css/pages/calendar.css`
- 진단 서비스: `public/js/services/diagnosis.js`
- 재사용 진단 흐름: `public/js/ui/diagnosis-flow.js`
- 개발 확인 버튼: `public/js/pages/dev-ui.js`의 `[P1]` 구역

이 폴더는 P1 작업 모음이며, 앱은 `public/` 아래의 모듈을 불러옵니다.
